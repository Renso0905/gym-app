# gym-app

Personal gym-tracking progressive web app. Built through the
[ai-factory](https://github.com/Renso0905/ai-factory), which supplies its
quality-control pipeline.

```bash
npm ci
npm run dev        # local development
npm run typecheck
npm test
npm run build
```

- What it should do: `docs/REQUIREMENTS.md`
- How it is built: `docs/ARCHITECTURE.md`
- Rules for the AI developer: `CLAUDE.md`

Changes reach `main` only through pull requests that pass the factory checks.
